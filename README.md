# Idol Taite Radar (アイドル・タイテ・レーダー)

複数アイドルのライブスケジュール一元管理 ＆ 対バン推し被り・タイテ照合（出番ギャップ・重複）判定スマホWebアプリ

---

## 🌟 開発背景・解決する課題

アイドルオタクが直面する以下のリアルな悩みを解決するために開発されました：

1. **「告知を追いきれない」**
   - 複数アイドルのX（Twitter）告知やTIGETページを1つずつ追うのが大変。
   - **解決**: 告知ツイートをコピペするだけで、タイトル・日付・会場・時間・出演推しグループ・タイテ枠を自動パースして即座にカレンダー＆リストに取り込めます。

2. **「AとBが被ったら行きたい」**
   - 対バンフェスで、本命（Sランク）と準推し（Aランク）が両方出るイベントだけを効率よく見つけたい。
   - **解決**: 推しグループの優先度（S/A/B）をもとに「🔥 S+A被り」「✨ 2組以上出演」を自動スコアリングしてバッジ表示＆ワンタップ絞り込み。

3. **「被っても出番が違ったら行かんでええか」**
   - 「AとBが出るけど出番が7時間離れていて待機が長すぎる」「出番時間が被っていて片方しか見られない」などのミスマッチ。
   - **解決**: 
     - 🎯 **神タイテ**: 出番が連続または0〜15分空き（行く価値大！）
     - ⏳ **離れすぎ警告**: 出番が60分以上離れている（「行かんでええか」の判定材料）
     - ⚡ **重複警告**: 出番時間が完全に被っている（タイテ被り）
     - グラフィカルな並列タイムラインバーで視覚的に照合可能。

4. **「スマホで片手操作したい」**
   - ライブハウスや移動中に親指だけでスムーズに使えるモバイルファースト設計。

## 🚀 起動方法

cd C:\Users\srapi\.gemini\antigravity-ide\scratch\idol-schedule-app
npx serve .
# または
python -m http.server 8080

PCで開いても、中央にスマホ最適化フレームで快適に操作できます。
